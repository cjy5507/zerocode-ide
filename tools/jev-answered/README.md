# jev-answered — 좌석마다 판정이 어떻게 끝났는지를 공급자 폴더와 시간대별로 (t-55423)

판정 공급자를 고치는 과업의 전/후 표를 만든다. 원장의 원자료만 센다. 한 줄에서 꺼내는 것은 좌석(원장 파일 이름), 공급자
폴더, 시각(`at`), 결과(`outcome`), 보낸 수(`requests`), 기억 답(`cached`), 적용(`applied`), 두 번째 질문(`probe`),
공급자 이름(`model`의 앞부분), 요청 시점 경로(`clientRoute`), 채점 기준 판(`rubricVersion`)뿐이다. 단어 모양이 아닌
결과 값은 `outcome_not_a_word` 하나로 세어, 행의 다른 글이 표에 실리지 않게 한다.

**Jev 요청 0건, 홈 쓰기 0건.** 쓰는 파일은 `--json` 이 이름 붙인 것 하나뿐이다.

| 조각 | 무엇 |
| --- | --- |
| `answered.py` | `<zo 홈>/jev/` 와 각 프로젝트의 `projects/<slug>/state/smart-router/` 에서, 폴더 자체(Jev 공급자, 표에는 `(jev)`)와 `providers/<이름>/` 마다 원장을 읽는다. 좌석·자리(창/프로젝트 합계)·공급자 폴더·시간대마다 판정, 보냄, 시도, 보낸 것 중 답함과 그 비율, 적용, 안 보냄(기억 답·얹혀 답함·대조군·보내기 전 실패), 재시도, 두 번째 질문, 다른 공급자를 적은 행, 미귀속, 경로별 수, 보낸 것 중 실패(많은 순)를 낸다. 그 아래에 공급자 폴더와 시간대별 합계, 읽은 파일마다 바이트·줄·깨진 줄·시각 없는 판정·sha256을 낸다 |
| `tools/tests/test_jev_answered.py` | 위의 셈이 행 자신의 칸으로만 정해지는지, 결과 단어 말고는 행의 글을 싣지 않는지, 홈을 그대로 두는지, 키와 단어와 폴더 이름이 Rust와 같은지 (`just tools-test`) |

폴더 이름(`jev`, `state/smart-router`, `providers`)은 `tools/jev-seat-replay/replay.py` 의 상수를 그대로 쓴다.

## 돌리기

```sh
python3 tools/jev-answered/answered.py \
    --window "before=2026-10-15T10:30..2026-10-15T12:30" \
    --window "after=2026-10-15T15:00..2026-10-15T17:00" \
    --ran window=1.1.67@2026-10-15T09:59:42.. --ran zo=1.1.67@2026-10-15T09:59:45.. \
    --app /Applications/ZeroCode.app --zo ~/.local/bin/zo \
    [--project <프로젝트 경로>] [--home <zo 홈>] [--json <out.json>]
```

| 손잡이 | 무엇 |
| --- | --- |
| `--window` | `이름=시작..끝`. 시각은 로컬 `YYYY-MM-DDTHH:MM[:SS]`, `Z`나 시차가 붙은 시각, epoch 밀리초 중 하나다. 비운 끝은 열림이다. 시작은 넣고 끝은 뺀다. 표에는 UTC로 적는다. 없으면 `all` 하나 |
| `--project` | 읽을 프로젝트(여러 번 가능). zo 의 slug 규칙으로 폴더 하나를 찾고, 없거나 둘이면 거절한다. 없으면 모든 프로젝트를 합친다 |
| `--ran` | `window` 또는 `zo` `=판@시작..끝`. `ps` 로 본 프로세스 하나: 시작 시각, 실행 경로, 그 번들이나 바이너리의 판. 창은 창의 행을, zo 는 프로젝트의 행을 쓴다. 행은 쓰인 때 그 쓰는 쪽이 돌린 판 하나를 받는다. 어느 프로세스도 덮지 않거나 두 판이 함께 덮는 행은 `unknown` 으로 따로 센다. 전/후는 같은 실행 판의 행끼리 견준다 |
| `--app`, `--zo` | 설치된 앱과 zo. 버전과 그 파일이 바뀐 시각을 적고, 그 시각이 든 시간대에 표시를 붙인다. 설치된 판은 어느 행의 판도 정하지 않는다 |
| `--home` | 읽을 zo 홈(기본 `~/.zo`) |
| `--json` | 표의 행, 합계, 시간대, 버전, 읽은 파일을 JSON 으로도 |
