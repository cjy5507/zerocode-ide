# 질문을 읽을 수 있는 차트

ZeroCode 아티팩트에 데이터를 그릴 때 사용한다. HTML 작성 전에 `Skill`로 `artifact-design`을 읽고
그 스킬의 목적별 구성·표현·제목·테마·발행 규칙을 적용한다. 데이터 출처·기준일·단위·결측값을 먼저 확인한다.
추정치와 관측치를 구별하고, 예시 데이터라면 화면에서 예시라고 밝힌다.

## 형태 고르기

| 알고 싶은 것 | 기본 형태 | 판단 기준 |
| --- | --- | --- |
| 항목 간 크기 | 정렬한 가로 막대 | 긴 이름은 옆에, 막대의 수량 축은 0에서 시작 |
| 시간에 따른 변화 | 선 | 실제 시간 간격 유지, 결측 구간을 선으로 메우지 않음 |
| 분포·이상값 | 히스토그램·점·상자 | 구간 폭과 표본 수 표시, 평균 하나로 분포를 숨기지 않음 |
| 두 값의 관계 | 산점도 | 축 단위·표본 수, 상관관계를 원인으로 말하지 않음 |
| 구성 비율 | 누적 막대 | 전체와 분모를 표시, 조각이 많으면 표나 막대 |
| 여러 집단의 추세 | 작은 다중 차트 | 공통 축과 일관된 범례, 겹친 선이 많아지면 분리 |

차트마다 읽어야 할 결론을 한 문장으로 적는다. 축 단위를 제목에 맡기지 않는다.
이중 축·3D·면적 장식은 기본으로 쓰지 않는다. 차이를 확대하려고 축을 잘랐다면 분명히 표시한다.

## 색은 이 표 한 곳에서

콘텐츠·브랜드·선택한 아트 디렉션에 맞는 범주·순서·발산 팔레트를 고른다.
색은 아티팩트의 한 토큰 집합에 `--series-*` 등의 의미 있는 이름으로 정의하고 SVG·차트 설정에서 읽는다.
같은 항목은 필터와 여러 차트에서도 같은 색이다. 강조하지 않는 정보는 같은 집합의 보조 텍스트 토큰을 쓴다.
별도 팔레트를 강제하거나 페이지의 토큰 값을 차트 설정에 다시 복사하지 않는다.

값의 순서에는 명도, 의미 있는 중심값에는 발산 팔레트를 쓴다. 범주색에 수치의 크기를 부여하지 않는다.
빨강·초록 구별만으로 성공·실패를 전하지 않는다. 색 외에 직접 레이블·선 모양·기호를 병용한다.

## 읽기·상호작용·발행

SVG는 `role="img"`와 `<title>`·`<desc>`를 연결한다. Canvas 차트에는 같은 값을 읽는 표와 요약을 제공한다.
툴팁은 포인터 없이도 접근하게 하고, 키보드 포커스와 단위를 유지한다. 필터는 무엇을 제외했는지 보여 준다.
빈 데이터·모든 값이 같음·음수·긴 이름·작은 화면을 확인하고 숫자 합계와 축 범위를 원자료에 대조한다.

단순한 차트는 인라인 SVG로 충분하다. 라이브러리가 필요하면 `artifact-design`의 CDN 규칙을 따른다.
양 테마에서 텍스트·선·선택 상태를 확인하고, 완성된 HTML을 `Artifact publish`로 발행해 반환 URL을 건넨다.
