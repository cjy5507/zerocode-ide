# 완성물을 페이지로

ZeroCode의 Artifact로 발행할 HTML을 쓰기 전에 이 스킬을 Skill로 읽는다.
차트가 중심이면 dataviz, 관계를 설명하는 그림이면 artifact-diagramming도 읽는다.
사용자의 형식·브랜드·참고 화면이 먼저다. 목적과 독자의 다음 행동을 정하고 실제 내용을 디자인한다.

## 목적이 구성을 정한다

| 사용 목적 | 구성의 기준 |
| --- | --- |
| 비교·선택 | 같은 기준으로 정렬한 선택지, 중요한 차이, 선택의 근거 |
| 상태 관찰 | 지금 상태, 변화, 예외. 필요한 곳에만 강조 |
| 조작 | 입력·선택·실행·결과·실패·초기화가 이어지는 완결된 흐름 |
| 설명·설득 | 핵심 메시지, 이를 증명하는 순서와 시각 자료 |
| 탐색 | 찾기·필터·미리보기·상세로 점진적으로 정보 노출 |

보고서를 랜딩 페이지처럼 만들거나 모든 내용을 같은 크기 카드로 나누지 않는다.
짧은 메모는 짧게, 대시보드는 실제 데이터와 조작에, 작은 앱은 한 가지 완결된 기능에 투자한다.

## 표현에는 의도가 있어야 한다

화려하고 인상적인 디자인을 원하면 소극적인 기본 문서에 머물지 않는다.
콘텐츠에 맞는 큰 타이포, 비대칭 구성, 색 대비, 레이어, 직접 만든 SVG·도형·이미지로
시각적 중심을 만든다. 표·본문·입력의 읽기와 조작은 선명하게 남긴다.
모션은 등장·선택·전환·상태 변화의 의미를 보이며, 유휴 화면에 무한 애니메이션을 얹지 않는다.

기존 토큰·브랜드 자료·참고 화면을 먼저 읽는다. 자료가 없으면 목적에 맞는 방향을 선택하고
한 문장으로 설명한다. 매번 같은 팔레트·폰트·레이아웃을 복제하지 않는다.
표현의 강도는 요청에 맞추고, 수치를 장식용 대형 숫자로 부풀리지 않는다.
색·글꼴·타입 크기·간격·곡률·그림자·모션은 한 디자인 토큰 집합에서 정의하고
본문·SVG·차트·조절판은 그 정의를 참조한다. 사용자 브랜드가 있으면 그 값이 원본이다.

## 시안·조절·피드백

방향 선택이 중요한 요청에만 정보 구조·밀도·타이포·상호작용이 다른 시안을 제시한다.
색만 바꾼 시안을 늘리지 않는다. 작은 수정과 명확한 요청은 바로 완성한다.
선택한 방향을 최종본으로 정리하고 이전 버전은 발행 이력에 남긴다.

비교에 도움이 될 때만 작은 조절판으로 밀도·글자 크기·테마·레이아웃을 조절하게 한다.
컨트롤을 실제 CSS 토큰이나 데이터에 연결하고, 숨겨도 완성물로 읽히게 한다.
선택값을 localStorage에만 두지 않는다. 발행·내보내기 전에 CSS/데이터에 반영해서
다른 브라우저에서도 선택한 모습이 되게 한다. 초기화는 같은 원본 토큰을 읽는다.
작동하지 않는 버튼과 가짜 성공 상태는 두지 않는다.

주석은 파일·버전·대상 요소·의견을 함께 확인한다. 기존 브라우저의 요소 주석,
스크린샷 마크업, 에이전트 전달을 쓴다. 다른 버전의 같은 좌표를 같은 요소로 추측하지 않는다.
수정한 부분을 다시 확인한 뒤 검사한 바로 그 파일을 발행한다.

## 제목과 테마

내용을 구별하는 고유명을 쓰고 Dashboard·Report·Untitled만 제목으로 쓰지 않는다.
HTML title·화면 제목·발행 title을 맞춘다. 설명은 누구의 어떤 판단을 돕는지 한 문장,
파비콘은 의미 있는 이모지 1~2개다.

본문 배경을 명시한다. 사용자 테마가 우선이며 별도 지시가 없으면 라이트를 기본으로 한다.
prefers-color-scheme은 수동 선택이 없을 때만 따른다. data-theme의 수동 선택이 항상 이긴다.
양 테마에서 텍스트·차트·SVG·포커스가 읽혀야 한다. 한국어는 단어 단위 줄바꿈,
숫자는 tabular-nums로 정렬한다. 외부 폰트는 필수 의존성이 되지 않도록 폴백을 둔다.

## 한 파일과 실제 확인

- CSS·스크립트·SVG·데이터·작은 이미지는 HTML 안에 둔다. 발행은 HTML 한 파일을 복사한다.
  상대 JS/CSS/이미지가 남으면 원본 폴더 밖에서 깨진다. 비밀값은 HTML에 넣지 않는다.
- 외부 라이브러리가 필요할 때만 cdn.jsdelivr.net 또는 cdnjs.cloudflare.com을 쓰고 버전을 고정한다.
  다른 호스트는 사용자가 지정한 경우 따른다. CDN이 막혀도 요약·표·설명이 남아야 한다.
- 첫 화면에 핵심 판단이나 작업이 드러나야 한다. 제목만으로 한 화면을 채우지 않는다.
- 좁은 화면에서는 열을 접고 넓은 표·그림에만 가로 스크롤을 허용한다.
  긴 한국어·긴 제목·빈 데이터·오류 상태도 확인한다.
- 실제 브라우저에서 핵심 상호작용·키보드 포커스·콘솔 오류·좁고 넓은 폭·양 테마를 확인한다.
  reduced-motion에서는 필수 정보가 남고 장식 모션이 멈춰야 한다.
- 효과를 비교할 때는 같은 내용·뷰포트·조건을 쓴다. 시안 수와 장식 수를 품질 점수로 삼지 않는다.
- 확인한 파일 경로를 Artifact의 publish에 전달한다. 같은 경로는 같은 링크의 새 버전이 된다.
  결과의 URL을 그대로 전달한다. 이 기계의 URL을 공개 공유 링크라고 부르지 않는다.

검증한 범위와 확인하지 못한 부분을 구분해서 보고한다.
